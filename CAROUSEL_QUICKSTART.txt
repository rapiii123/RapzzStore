# Carousel Banner - Quick Start Checklist ✅

## 1️⃣ Database Setup
- [ ] Jalankan: `php artisan migrate`
- [ ] Jalankan: `php artisan storage:link`

## 2️⃣ Test Carousel
- [ ] Buka halaman utama: http://localhost/
- [ ] Carousel muncul di atas "🔥 Top Up Games"
- [ ] Tombol Previous/Next berfungsi
- [ ] Auto-slide setiap 5 detik
- [ ] Indicator dots berfungsi

## 3️⃣ Upload Banner Pertama
- [ ] Login ke aplikasi (atau disable auth untuk testing)
- [ ] Akses: http://localhost/admin/banners
- [ ] Klik "+ Upload Banner"
- [ ] Upload image (1200x400px recommended)
- [ ] Isi judul & deskripsi
- [ ] Klik Upload

## 4️⃣ Verify Banner
- [ ] Kembali ke homepage
- [ ] Banner yang baru di-upload muncul di carousel
- [ ] Test semua functionality

## 🛠️ If You Need Help

1. **Carousel tidak muncul?**
   - Check browser console (F12) untuk error
   - Reload halaman

2. **Upload image gagal?**
   - Pastikan folder `storage/app/public/banners/` exist
   - Check file permission (chmod 755)
   - Cek ukuran image (max 5MB)

3. **Admin page butuh login?**
   - Edit routes di `web.php` line ~50
   - Remove `->middleware('auth')` untuk public access
   - Atau setup authentication terlebih dahulu

---

## 💡 Pro Tips

- Gunakan image dengan aspect ratio 3:1 (1200x400, 900x300, etc)
- Compress images sebelum upload untuk performa lebih baik
- Optimize image dengan tools seperti TinyPNG, ImageOptim
- Sesuaikan interval auto-slide dengan mood banner
- Tambah link di banner untuk redirect ke halaman promo
